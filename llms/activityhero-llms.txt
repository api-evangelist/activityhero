# ActivityHero

> ActivityHero is a marketplace connecting families with kids' camps, classes, and enrichment activities — a one-stop shop to find top-rated summer camps, holiday camps, and after-school classes. It also provides registration and marketing software for activity providers (MarketingHero, registration software) and programs for school districts.

ActivityHero does not publish a REST API or OpenAPI. Its provider integration surface is delivered as outbound, HMAC-SHA256-signed JSON webhooks configured per-provider under "Manage Listing > API". This file was generated from apis.yml and the repo's captured artifacts.

## Integration (Webhooks)
- [API help center](https://help.activityhero.com/api): Overview of ActivityHero's Registration API and Schedule API.
- [Registration API](https://help.activityhero.com/can-i-sync-activityhero-registrations-to-my-own-database): Sync registrations to your own database via signed webhook POSTs (action = enrolled/update/cancelled).
- [Schedule API](https://help.activityhero.com/can-i-sync-my-activity-schedules-into-activityhero): Keep external activity schedules in sync (JSON, max 100 sessions per call; CSV import for larger batches).
- [Registration API with Zapier](https://help.activityhero.com/how-do-i-use-the-activityhero-registration-api-with-zapier): Catch registration webhooks with a Zapier "Catch Raw Hook".
- Authentication: HMAC-SHA256 signature over "providerID_timestamp" in a Signature header (per-provider secret from the dashboard).
